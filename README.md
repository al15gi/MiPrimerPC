# Mi Primer PC

Catálogo actualizado en septiembre de 2026 para GitHub Pages.

Incluye:
- 💶 Presupuesto bajo
- ⚡ Presupuesto medio
- 🚀 Presupuesto alto
- 💻 Portátiles
- 🎮 Gaming
- ⌨️ Periféricos
- 👨‍💻 Programación
- 🔎 Buscador

La selección se ha construido usando búsquedas recientes de hardware y portátiles de 2026. Por ejemplo, guías españolas de septiembre de 2026 sitúan RTX 5060/RX 9060 XT en torno al tramo de 1.000 € para gaming 1080p, y configuraciones con RTX 5070/5070 Ti o GPUs superiores en gamas más altas. Apple confirma las especificaciones del MacBook Air M5 de 2026.

## Importante sobre Amazon

Los enlaces de esta versión llevan a búsquedas específicas de Amazon, no a la portada. Para monetización, sustituye cada campo `enlace` de `productos.json` por tu enlace de afiliado generado para el producto concreto cuando tengas tu cuenta de Amazon Afiliados.

Los precios son orientativos y pueden cambiar.
