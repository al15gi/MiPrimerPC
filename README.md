# MiPrimerPC — catálogo con modelos concretos

Esta versión sustituye nombres genéricos por modelos/referencias concretas siempre que se ha podido verificar el producto. Las imágenes se sirven desde fichas reales de producto; no se usan fotos genéricas de hardware.

Los enlaces de compra llevan a búsquedas exactas en Amazon.es o a la ficha oficial cuando corresponde. Para afiliación de Amazon, sustituye cada `enlace` por el enlace de producto generado desde Amazon Afiliados cuando tengas la referencia exacta.

Precios y disponibilidad pueden cambiar.
